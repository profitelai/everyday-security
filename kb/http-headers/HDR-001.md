# HDR-001 · Strict-Transport-Security is sent on every HTTPS response

## Why it matters
HSTS tells the browser to use HTTPS only for the site, which closes the window in which a first HTTP request could be intercepted and blocks click-through on certificate errors.

## How to test
```bash
curl -sI https://example.com/ | grep -i strict-transport-security
```

## Pass criteria
The header is present with `max-age` of at least 15552000 (180 days); one year (31536000) is the usual target. `includeSubDomains` is present once every subdomain serves HTTPS.

## Fix
`Strict-Transport-Security: max-age=31536000; includeSubDomains`. Start with a short max-age (for example 300) for a day, confirm nothing breaks, then raise it. Add `always` in nginx so it is also sent on error responses.

## Risk and rollback
Browsers cache the policy; if HTTPS breaks later, visitors cannot bypass it until max-age ends. Do not add `preload` until you accept that removal from the preload list takes months.
