# HDR-009 · Server and framework version banners are not exposed

## Why it matters
Exact software versions in `Server`, `X-Powered-By` or `X-AspNet-Version` headers tell an attacker which known vulnerabilities to try. Hiding the version does not fix a vulnerability, but it removes free reconnaissance.

## How to test
```bash
curl -sI https://example.com/ | grep -iE '^(server|x-powered-by|x-aspnet|x-generator)'
```

## Pass criteria
No header discloses a version number. A bare product name (`nginx`) is acceptable.

## Fix
nginx: `server_tokens off;`. Apache: `ServerTokens Prod` and `ServerSignature Off`. PHP: `expose_php = Off`. Remove framework banner headers in its configuration.

## Risk and rollback
None. Version hiding must never be used instead of patching.
