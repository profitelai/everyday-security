# HDR-006 · Permissions-Policy switches off browser features the site does not use

## Why it matters
If your site does not need the camera, microphone, geolocation or payment APIs, an injected script or an embedded third party should not be able to request them either.

## How to test
```bash
curl -sI https://example.com/ | grep -i permissions-policy
```

## Pass criteria
A policy is present and disables the features the site does not use, for example `camera=(), microphone=(), geolocation=()`.

## Fix
`Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()`. Allow a feature only for `self` or a named origin if the site really uses it.

## Risk and rollback
Disabling a feature the site does use (video calls, maps, payment buttons) breaks it. List the features in use before choosing the policy.
