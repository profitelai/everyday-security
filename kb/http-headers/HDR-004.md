# HDR-004 · X-Content-Type-Options: nosniff is sent

## Why it matters
Without it, a browser may guess a file's type from its content and run an uploaded text or image file as a script. The header makes the browser trust the declared type.

## How to test
```bash
curl -sI https://example.com/ | grep -i x-content-type-options
```

## Pass criteria
The header is present with the exact value `nosniff` on HTML, script and stylesheet responses.

## Fix
`add_header X-Content-Type-Options nosniff always;` (nginx) or `Header always set X-Content-Type-Options nosniff` (Apache). Make sure every resource is served with the correct Content-Type.

## Risk and rollback
Resources served with a wrong type (for example a script sent as text/plain) stop working. Fix the type rather than removing the header.
