# TLS-005 · DNS CAA records restrict which authorities may issue certificates

## Why it matters
A CAA record tells certificate authorities that only the listed ones may issue for the domain. It does not stop a determined attacker, but it blocks accidental or opportunistic mis-issuance and gives a clear audit trail.

## How to test
```bash
dig +short CAA example.com
dig +short CAA www.example.com
```

## Pass criteria
At least one CAA `issue` record exists for the apex and names only the authority actually in use. An `iodef` record with a monitored mailbox is a bonus.

## Fix
Add for example `example.com. CAA 0 issue "letsencrypt.org"` (replace with the CA you use). If you use several CAs list each one.

## Risk and rollback
A CAA record for the wrong CA will make the next renewal fail. Add the record for the current CA first, and test a renewal in a staging window.
