# APP-003 · Anything a visitor can supply is encoded for its output context

## Why it matters
Cross-site scripting happens when text from a visitor (a search term, a comment, a profile name) is written into a page as live markup. The attacker's script then runs in a victim's browser with that victim's session, so it can act as them. The OWASP Top 10:2021 lists XSS under Injection (A03). The dependable fix is to encode on output for the exact place the value lands.

## How to test
Use a harmless marker that contains markup characters but no script. Put it in every search box, query parameter, form field and profile field you own.
```bash
curl -s 'https://example.com/search?q=zq%22%27%3Cb%3Eprobe%3C%2Fb%3Ezq' | grep -o 'zq.\{0,40\}probe.\{0,20\}zq'
```
If the response shows `&lt;b&gt;probe&lt;/b&gt;` with the quotes also encoded, the value was encoded. A raw `<b>probe</b>`, or an unescaped quote inside an attribute, means the output is not safe. For stored fields (comments, names), submit the marker, then view the page that displays it, including admin views, emails and exports. Check templates for escape-bypass calls (`|safe`, `{!! !!}`, `v-html`, `innerHTML`, `dangerouslySetInnerHTML`, PHP `echo $_GET[...]`).

## Pass criteria
The marker comes back encoded in every HTML body, attribute, and script context tested. Templates use the framework's auto-escaping by default and any bypass is limited to content the site itself produced or sanitized with a maintained library.

## Fix
Use a template engine with auto-escaping on, and in plain PHP wrap output in `htmlspecialchars($v, ENT_QUOTES, 'UTF-8')`. Never place user data inside `<script>` blocks or event-handler attributes. If rich text is required, sanitize it with a maintained HTML sanitizer. Add a Content-Security-Policy as a second layer (see HDR-002).

## Risk and rollback
Encoding twice shows literal `&amp;` on pages that were already escaping; fix at the output point only. Rollback: revert the template change; stored data should be kept raw and encoded at output, so data does not need migrating.
