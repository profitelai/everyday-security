# CTR-007 · Containers have memory, CPU and process limits and a restart policy

## Why it matters
By default a container may use as much memory, CPU and process slots as the host has. One leaky or abused service can then starve every other container on the machine, including the database and the SSH daemon, so a single fault becomes a full outage. Limits turn a host-wide failure into one container being stopped and restarted. A restart policy brings services back after a crash or reboot, without which a short fault stays down until someone notices.

## How to test
```bash
docker ps -q | xargs docker inspect --format \
 '{{.Name}} mem={{.HostConfig.Memory}} cpus={{.HostConfig.NanoCpus}} pids={{.HostConfig.PidsLimit}} restart={{.HostConfig.RestartPolicy.Name}}'
docker stats --no-stream
free -h
```
`mem=0` means unlimited. Compare the sum of the limits to the host's memory, and look for containers whose usage in `docker stats` is close to their limit.

## Pass criteria
Every long-running container has a memory limit sized from observed use with headroom, a process limit where supported, and a CPU limit or share where several services compete. The memory limits together leave room for the host itself. Production services use a restart policy such as `unless-stopped` (or `on-failure` with a cap), and the OOM-kill count is watched.

## Fix
In Compose use the service-level keys (`mem_limit`, `cpus`, `pids_limit`, `restart: unless-stopped`) or the `deploy.resources.limits` form that current Compose also honours. Start from measured usage (`docker stats` over a normal week), set the limit around 1.5 to 2 times the peak, and revisit when the workload grows. Add an alert on container restarts (SRV-012).

## Risk and rollback
A limit set too low makes the kernel kill the process when it runs out of memory, which looks like random crashes under load; check `docker inspect --format '{{.State.OOMKilled}}' CONTAINER` after any restart. Raise limits gradually. Rollback: remove or raise the limit in Compose and recreate the container.
