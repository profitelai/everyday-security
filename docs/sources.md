# Source ledger

Every check in `kb/` cites sources by ID from this table. Sources are public standards and primary documentation, consulted directly. Text is written in our own words; standards are referenced, never pasted. Licenses of the sources are noted so that nothing is reused in a way they do not allow (OWASP cheat sheets are CC BY-SA 4.0: we cite them, we do not copy their text).
