# Sources: privacy-compliance pillar

Primary public sources for the PRIV checks. Each was retrieved and read on 2026-11-09. Text in the knowledge base is our own wording; nothing is pasted. Legislation text is read from the official consolidated versions; Commission d'acces a l'information (CAI) pages are plain-language guidance and the CAI itself states that the legislation prevails over them. LegisQuebec answers HTTP 403 to clients that send no browser-style User-Agent; with one it returns 200.
