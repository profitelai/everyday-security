# Incident response

[← Coverage](../README.md)

Plan, owners, contacts, evidence, logging, communication, recovery and post-incident review.

**10 checks** · 0 run automatically · 0 in the server audit · 10 guided checklists · for: Any business

| ID | Check | Severity | How it is run | Standards |
|---|---|---|---|---|
| [IR-001](../../kb/incident-response/IR-001.md) | A short written incident response plan exists and can be opened when systems are down | high | Guided checklist | NIST SP 800-61 Rev. 3, ISO/IEC 27035 |
| [IR-002](../../kb/incident-response/IR-002.md) | One incident lead and a deputy are named and have written authority to isolate systems | high | Guided checklist | NIST SP 800-61 Rev. 3 |
| [IR-003](../../kb/incident-response/IR-003.md) | A current incident contact list covers internal staff, providers, advisers and authorities, and is kept off the systems it protects | medium | Guided checklist | NIST SP 800-61 Rev. 3 |
| [IR-004](../../kb/incident-response/IR-004.md) | Security alerts reach a person, staff know how to report a suspected incident, and severity is ranked with a simple scale | high | Guided checklist | NIST SP 800-61 Rev. 3 |
| [IR-005](../../kb/incident-response/IR-005.md) | Containment steps are rehearsed per system, and evidence is preserved before anything is wiped or rebuilt | high | Guided checklist | NIST SP 800-61 Rev. 3, NIST SP 800-86 |
| [IR-006](../../kb/incident-response/IR-006.md) | Logs needed to investigate an incident are kept off the host for long enough, with synchronized clocks | high | Guided checklist | NIST SP 800-92, NIST SP 800-61 Rev. 3 |
| [IR-007](../../kb/incident-response/IR-007.md) | Communication owners, holding statements and a regulator-notification pointer sheet exist before an incident | high | Guided checklist | Law 25 (Quebec), PIPEDA, NIST SP 800-61 Rev. 3 |
| [IR-008](../../kb/incident-response/IR-008.md) | Recovery is done from known-good sources with credentials rotated, and every incident ends with a written review and tracked actions | medium | Guided checklist | NIST SP 800-61 Rev. 3, NIST SP 800-34 |
| [IR-009](../../kb/incident-response/IR-009.md) | A tabletop exercise is run at least once a year and its findings change the plan | medium | Guided checklist | NIST SP 800-61 Rev. 3 |
| [IR-010](../../kb/incident-response/IR-010.md) | A one-page 'first hour' sheet is printed, current and used by whoever answers first | high | Guided checklist | NIST SP 800-61 Rev. 3 |

All checks are drafts (Alpha). Each check page explains why it matters, how to test it, the pass criteria, the fix and the risk of the fix.
